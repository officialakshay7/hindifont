Website में Noto Sans Devanagari Add करें

किसी भी website में Hindi font add करना 2 steps में होता है:

Step 1 — HTML में add करें:

<link href="https://fonts.googleapis.com/css2?family=Noto+Sans+Devanagari:wght@400;600;700&display=swap" rel="stylesheet">

Step 2 — CSS में set करें:

body { font-family: 'Noto Sans Devanagari', sans-serif; }

💡 Performance Tip: हमेशा display=swap URL में include करें। इससे page तुरंत system font में दिखेगा और Hindi font load होने पर swap होगा — Core Web Vitals score बेहतर होगा।
