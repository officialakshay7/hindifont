Richa Font क्या है?

Richa एक elegant Hindi ANSI font है जो magazines, literary publications और aesthetic projects के लिए widely used है।

Graceful letterforms जो reading experience को enhance करते हैं।

Install कैसे करें? (Windows)

1

Official source (विभाग / publisher) से font की .ttf file प्राप्त करें।

2

Right-click → Install।

💡 Mac पर Install: .ttf file को Font Book app में drag करें → Install Font click करें। Done!

Website में Richa Add करें

HTML में add करना simple है:

<link href="https://fonts.googleapis.com/css2?family=Richa&display=swap" rel="stylesheet">

CSS में: font-family: 'Richa', sans-serif;

Performance Tips

Web fonts page speed को affect करते हैं। Best practices:

1. सिर्फ ज़रूरी weights load करें (Regular 400 और Bold 700 usually enough)।

2. display=swap always include करें।

3. <link rel="preconnect"> fonts.googleapis.com के लिए add करें।

💡 Font Stack: Fallback fonts भी specify करें: 'Richa', 'Noto Sans Devanagari', sans-serif — इससे font load होने से पहले भी Hindi text readable रहेगा।
