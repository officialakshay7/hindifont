Hindi typing सीखने से पहले सबसे important decision यह है: Remington keyboard सीखूँ या Inscript? गलत choice = wasted months। यह guide एक बार में सही decision लेने में help करेगी।

Two Layouts — Two Different Worlds

Hindi typing में basically दो keyboard systems हैं — Remington (ANSI fonts के लिए) और Inscript (Unicode fonts के लिए)। दोनों fundamentally अलग हैं — एक सीखने पर दूसरा automatically नहीं आता।

Remington Layout — क्या है, किसके लिए

Remington layout 1950s-60s के Hindi typewriters से आया है। India में पहले जो typewriters use होते थे, उनकी key positions को computer keyboard पर map किया गया — यही Remington layout है।

Fonts: Kruti Dev 010, Devlys 010, Walkman Chanakya — सभी ANSI fonts।

Exams: SSC CHSL/CGL, UP Police, Railway, High Court clerk।

Characteristic: English keys को Hindi characters की तरह treat किया जाता है। 'k' press करो → 'क' type होता है।

Inscript Layout — क्या है, किसके लिए

Inscript (Indian Script) Government of India का standardized Hindi keyboard layout है। इसे specifically Hindi typing के लिए design किया गया — typewriter legacy नहीं है।

Fonts: Mangal (Unicode), सभी modern Unicode fonts।

Exams: CPCT (MP Government), government websites।

Characteristic: Vowels left side पर, consonants right side पर। Logically organized।

Remington vs Inscript — Head to Head

Aspect Remington Inscript
Learning Difficulty Moderate Moderate
Logic Typewriter-based Linguistically logical
SSC/UP Police ✅ Required ❌ Not accepted
CPCT Exam ❌ Not accepted ✅ Required
Online/Internet use ANSI — issues ✅ Unicode perfect
Available on Windows (Kruti Dev) Windows built-in
Future prospect Legacy, declining Growing, modern

आपके लिए कौन सा?

SSC/Railway/UP Police दे रहे हो?

Remington सीखो — Kruti Dev 010 के साथ। यही exam में use होगा।

CPCT exam की तैयारी है?

Inscript सीखो — Mangal font के साथ। CPCT में यही mandatory है।

Digital Hindi typing/blogging?

Inscript सीखो — Unicode standard है, internet पर everywhere काम करता है।

अभी तय नहीं है?

Remington सीखो — ज़्यादा government exams Remington specify करते हैं।

Inscript Windows में Setup

1

Settings → Time & Language → Language & Region open करें।

2

"Add a language" → Hindi → Next → Install।

3

Hindi → Language options → "Hindi Traditional Inscript" keyboard add करें।

4

Windows + Space से languages switch करें।

💡 Shortcut: Windows + Space keyboard language toggle करता है। Practice session में काम आएगा।
