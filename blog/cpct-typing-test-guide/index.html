CPCT Typing Test 2026 — Complete Guide

CPCT typing test 2026 complete guide. Mangal font, Inscript keyboard, 5000 KDPH speed requirement. MP government exam preparation tips.

CPCT (Computer Proficiency Certification Test) मध्य प्रदेश सरकार की सबसे important typing certification है। MP के सभी government jobs के लिए यह mandatory है।

CPCT Exam Structure

ComponentDetails
Hindi Typing FontMangal (Unicode)
Keyboard LayoutInscript
Hindi Speed Required5000 KDPH (~17-20 WPM)
English Speed8000 KDPH (~35 WPM)
Test Duration15 min Hindi + 15 min English
Certificate ValidityLifetime

3 Month Preparation Plan

Month 1

Mangal font verify करें (Windows में pre-installed)। Inscript keyboard enable करें। Home row keys सीखें। Daily 30 min।

Month 2

Full Inscript keyboard cover करें। Special characters सीखें। Daily timed tests लें।

Month 3

5000 KDPH target achieve करें। CPCT mock tests practice करें।

💡 CPCT Tip: KDPH = Keystrokes Per Hour। 5000 KDPH = approximately 17-20 WPM। Accuracy से ज़्यादा important है — errors KDPH घटाती हैं।

Inscript Keyboard Enable करें

Settings → Time & Language → Language → Hindi → Options → Add a keyboard → Hindi Traditional Inscript select करें। Taskbar में language icon से switch करें।
