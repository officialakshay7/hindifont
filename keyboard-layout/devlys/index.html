Key Tips

  • Home row (normal): a=ं, s=े, d=क, f=ि, g=ह | h=ी, j=र, k=ा, l=स, ;=य
  • ि (f) हमेशा consonant से पहले type होती है — जैसे कि = f + d
  • रेफ (र्) consonant के बाद Z से — जैसे कार्य = dk;Z
  • Full consonant = half form + k — जैसे भ = H + k
  • DevLys 010 की key mapping Kruti Dev 010 जैसी ही है — इसलिए यही chart दोनों के लिए काम करता है
  • Remington (GAIL) Unicode keyboard में भी ज़्यादातर keys इसी position पर हैं; कुछ conjuncts अलग हो सकते हैं — अपने exam notice से confirm करें

How to Print / Download

  • Screenshot lein — snipping tool use karein
  • PDF ke liye: Print → Microsoft Print to PDF select karein

Devlys Keyboard Layout Chart — Complete Learning Guide

Devlys Keyboard Layout Chart keyboard layout को master करना government typing exams pass करने की key है। यह layout एक बार अच्छे से सीख लिया तो lifetime काम आता है।

Keyboard layout chart को print करके अपने workstation पर रखें। Practice के दौरान reference के लिए helpful है। लेकिन goal यह होना चाहिए कि बिना देखे type कर सकें।

Layout Memorization Strategy

Week 1

Home Row: ASDF (left) और JKL; (right) — ये 8 keys पूरी keyboard की foundation हैं। इन्हें blindly type करने तक practice करें।

Week 2

Top Row: QWERT YUIOP — Home row से ऊपर। हर key practice के बाद home position पर return करें।

Week 3

Bottom Row: ZXCVB NM — Home row से नीचे। Pinky finger ज़्यादा use होती है — extra practice।

Week 4

Numbers + Shift: Special characters और number row। Shift keys से additional Hindi characters।

Print करें और Practice करें

यह keyboard chart print करने के लिए: Ctrl+P press करें → Landscape mode select करें → Print। या screenshot लेकर mobile पर save करें — practice के दौरान reference के लिए।

Chart को keyboard के ऊपर tape करें — पहले 2-3 दिन देख सकते हैं, लेकिन जल्दी से बिना देखे type करने की habit बनाएं।

💡 SSC/Railway Exam के लिए: Exam में keyboard chart नहीं मिलेगा — सब memory से होगा। इसलिए practice में भी chart बंद करके type करने की habit डालें।
